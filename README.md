# Low Poly Ghost Racer

This project is a static website game that can be hosted on GitHub Pages or any other web host.

## Files

- `index.html` — complete single-file game

## Controls

- `W` / `S` — accelerate / brake
- `A` / `D` — steer
- `Space` — handbrake
- `Shift` — shift up
- `X` — shift down
- `C` — toggle first/third person
- `R` — reset car
- Mouse — look around in first-person mode

## GitHub Pages setup

1. Upload the contents of this folder to a GitHub repository.
2. In GitHub, open the repository settings.
3. Go to Pages.
4. Set the source to the main branch (or the branch you want to publish).
5. Save.
6. Your site will be available at a GitHub Pages URL.

## Important note

This project is designed to run as a website. It will not work reliably if opened directly from `file://...` in some browsers because of local file restrictions.

Use it on a hosted site, or open it through a web server.
